# Моделирование бизнес-процессов: школа танцев

Учебный проект по дисциплине «Моделирование бизнес-процессов». Для вымышленной школы танцев описаны бизнес-процессы и спроектировано приложение. 

## Работы

1. **IDEF0 (AS-IS и TO-BE), DFD и IDEF3.** Описание предметной и проблемной областей, функционала приложения, целей организации. Модели процессов школы «как есть» и «как должно быть».
2. **SWOT-анализ и стандарты качества ISO 9001.** SWOT-анализ, цели исследования, критерии эффективности процессов, рекомендации по оптимизации, риски.
3. **SWOT, EPC и BPMN (ARIS).** Анализ проблемных областей, схема EPC обработки отзыва клиента, BPMN-диаграмма процессов «Управление компанией».
4. **UML: диаграммы прецедентов и классов.** Моделирование информационной системы школы танцев.
5. **C4: контекст, контейнеры, компоненты, код.** Четыре уровня архитектуры приложения.

## Инструменты

draw.io, PlantUML, Word.
